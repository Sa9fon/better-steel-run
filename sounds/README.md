# Your songs go here

Put your own MP3 files in this folder with these exact names:

| File | Popup option |
|---|---|
| `horse.mp3` | A Horse With No Name |
| `chain.mp3` | The Chain |

They aren't included in the repository because they're copyrighted recordings.
You can also skip this and choose **Custom Local File** in the popup to upload any MP3.
